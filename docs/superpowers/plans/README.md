# Superpowers Plans Archive

This directory is now treated as an implementation-plan archive for restart
purposes. Many files here describe work that has already been implemented or
superseded by the current closed-beta foundation.

Do not add new ideas to this directory. New product, UX, technical, workflow,
marketing or business ideas belong in GitHub Issues first and, when useful, in
the relevant current repository document such as `docs/ROADMAP.md`,
`docs/DECISIONS.md`, `docs/HANDOFF.md`, or an active
`docs/superpowers/specs/*` discovery/spec.

Current roadmap and release gates live in:

- `../../restart/folioloom-restart-spec.md`
- `../../restart/release-gates.md`
- `../../restart/two-week-engineering-plan.md`
- `../../../DOCUMENT_INDEX.md`

Do not treat unchecked boxes in old plan files as active roadmap items unless a
current restart doc explicitly reactivates that slice.
