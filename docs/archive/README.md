# Archive Index

This archive keeps the full pre-trim project memory available without loading it into every agent task.

Use the short bootstrap docs first. Open archive files only when the current task needs historical evidence, older rationale, detailed risk history, full routing tables or old repo-level skill wording.

## Project Memory

| Archive file | Use when |
| --- | --- |
| `project-memory/HANDOFF.full-before-trim.md` | You need issue-by-issue handoff history or older current-focus notes. |
| `project-memory/DECISIONS.full-before-trim.md` | You need the full decision log, rationale, dates or historical approval evidence. |
| `project-memory/ROADMAP.full-before-trim.md` | You need old phase/backlog candidates or historical prioritization. |
| `project-memory/RISK_REGISTER.full-before-trim.md` | You need detailed risk history, owner/role ownership or old mitigation text. |
| `project-memory/RELEASE_CHECKLIST.full-before-trim.md` | You need the full old release checklist, old Gate B/D details or prior release evidence wording. |
| `project-memory/CURRENT_PROJECT_STATE.full-before-trim.md` | You need the longer prior state snapshot and old verification notes. |

## Agent Routing

| Archive file | Use when |
| --- | --- |
| `agent-routing/AGENTS.full-before-trim.md` | You need the previous full agent contract. |
| `agent-routing/DOCUMENT_INDEX.full-before-trim.md` | You need the previous full document index. |
| `agent-routing/CONTEXT_MAP.full-before-trim.md` | You need the long context map, especially the old glossary/spec catalog. |
| `agent-routing/AGENT_SKILL_ROUTING.full-before-trim.md` | You need the full old skill dispatch tables, examples or domain catalog. |
| `agent-routing/QUALITY_GATES.full-before-trim.md` | You need the full old quality-gate matrix and detailed risk gates. |

## Repo Skills

`repo-skills/` contains the full pre-trim `.agents/skills/*/SKILL.md` files.

Use these only to compare old behavior or recover a rule that was intentionally removed from the thin repo-level skills.

## Archive Rule

Do not treat archive content as current instructions by default. If short docs and archive conflict, follow the current short docs unless the owner explicitly asks to restore old behavior.
