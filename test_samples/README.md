# Test samples

## Repository-generated fixtures

`sample_book.*`, Russian/Ukrainian profile regression samples, adversarial glossary
TXT/JSON fixtures and stress-test DOCX are repository-generated test material.
See `scripts/generate_sample_documents.py` and the related regression modules.

`synthetic_glossary_control.en.epub` is original deterministic long-form regression
material generated by `scripts/generate_synthetic_glossary_control.py`. It tests
large EPUB extraction, terminology selection and fake-provider boundaries. It is
not a literary text or evidence of translation quality.

## Private external fixtures

Full third-party EPUB books, unverified DOCX packs and translated artifacts are
excluded from branch history. Existing originals remain in the private archive.
Optional external fixtures belong in ignored `private_fixtures/`; absence of an
external fixture must not silently be presented as a real-book quality check.
A source-code license does not replace the separate conditions of those books.

Tests use local/fake providers. Provider-backed tools require deliberate configuration.
